# Security

Please report vulnerabilities through GitHub's private vulnerability reporting for this repository rather than opening a public issue.

Do not include credentials, browser cookies, signed publisher URLs, institutional identifiers, or downloaded papers in a report. A minimal reproduction with placeholder domains is preferred.

The supported security boundary is documented in the README. Reports that demonstrate arbitrary URL fetching, private-network access, unsafe redirect handling, arbitrary local-file access, credential exposure, or bypass of configured source limits are especially useful.
